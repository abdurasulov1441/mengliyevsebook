# Mengliyev's eBook — бэкенд

Сервер для приложения: API (совместим с текущим Flutter-приложением), веб-панель администратора и конвертер книг. Конвертер превращает Word-файл в формат, удобный для чтения на телефоне.

```
backend/
  src/converter/   Word/EPUB/TXT → пакет книги (главы, оглавление, сноски, картинки) + EPUB
  src/routes/      API: авторизация по SMS, книги, авторы, категории, оплаты, админка
  public/reader/   читалка (HTML/JS) — одна и та же в браузере, офлайн и в приложении
  public/admin/    веб-панель администратора (/admin)
  scripts/         convert.js (офлайн-режим), sync-reader.js, create-admin.js
  test/            сквозной тест API
```

## 1. Офлайн-проверка книг (без сервера)

```bash
cd backend
npm install
npm run convert -- "C:\путь\книга.docx" "C:\папка\с\книгами"
```

Откройте `backend/offline/index.html` двойным щелчком. Откроется библиотека, оттуда можно читать любую книгу. Чтобы увидеть книгу так, как на телефоне, включите в Chrome режим устройства (F12 → значок телефона).

Параметры: `--title "Название"`, `--author "Автор"`, `--cover обложка.jpg`, `--out папка`.

## 2. Сервер

```bash
cd backend
npm install
cp .env.example .env      # заполните (в репозитории уже есть локальный .env для разработки)
npm start                 # http://localhost:3000/admin/
```

Логин в панель берётся из `ADMIN_PHONE` / `ADMIN_PASSWORD` в `.env`.

SMS отправляются через GetSMS.uz. Пока `SMS_DRY_RUN=true`, коды не отправляются, а печатаются в лог сервера. В режиме разработки код `DEV_OTP_CODE` (по умолчанию `111111`) подходит для любого номера; в production он игнорируется. GetSMS принимает запросы только с разрешённых IP: перед запуском сообщите им IP сервера и поставьте `SMS_DRY_RUN=false`.

Тест: `npm test`.

### Production (Docker)

```bash
cd backend
cp .env.example .env   # NODE_ENV=production, JWT_SECRET, ADMIN_*, SMS_*, PUBLIC_URL
docker compose up -d --build
```

Образ включает LibreOffice: старые `.doc`, `.rtf` и `.odt` конвертируются полностью, с таблицами и картинками. Без LibreOffice из `.doc` извлекается только текст. Все данные лежат в `./data`: база `ebook.sqlite`, обложки, исходники и пакеты книг. Для резервной копии достаточно этой папки.

Перед сервером поставьте nginx/Caddy с HTTPS и `client_max_body_size 100m`.

## Как работает конвертер

В Word-файлах авторов обычно нет стилей заголовков: главы просто набраны жирным, крупнее и по центру. Поэтому pandoc, Calibre и «Сохранить как EPUB» выдавали либо одну бесконечную главу, либо сотни обрывков. Конвертер:

1. определяет размер основного текста и находит строки, которые выделяются: жирные, крупнее, по центру, после разрыва страницы;
2. уровни заголовков ставит по размеру шрифта и нумерации (`4.` → `4.1.` → `4.1.1.`);
3. склеивает номер главы со следующей строкой: «1» + «KIRISH», «1-mavzu» + название темы;
4. распознаёт титульный лист, название и авторов, а также ручное оглавление «Mundarija»;
5. не принимает за заголовки подписи справа, перечисления «a) …» и строки вида «Термин. Текст…»;
6. делит книгу на главы так, чтобы они не были крошечными или гигантскими;
7. переносит сноски в конец главы (в читалке они открываются по нажатию), сжимает картинки, проставляет блокам id для закладок.

Результат: `manifest.json` + `book.js` + `images/` + `book.epub` + `package.zip` (пакет для скачивания в приложении).

## Читалка

Пагинация как в книге (свайпы, тап по краям) или прокрутка; размер шрифта, гарнитура, интервал, поля, выравнивание; темы светлая/сепия/тёмная/чёрная; яркость; оглавление, закладки, цветные выделения с заметками, поиск по книге, сноски во всплывающем окне, увеличение картинок, переносы узбекских слов. Позиция, закладки и выделения синхронизируются между устройствами.

## API (основное)

| Метод | Путь | Кто |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login`, `/api/auth/verify`, `/api/auth/refresh` | все |
| POST | `/api/auth/admin-login` | админ (телефон + пароль) |
| GET | `/api/books/get-books?is_free=&category_id=&q=` | все |
| GET | `/api/books/my-books` | пользователь |
| GET | `/api/books/:id/package.zip` | пользователь с доступом |
| GET/PUT | `/api/books/:id/reading` | пользователь с доступом |
| POST/PUT/DELETE | `/api/books/create-book`, `update-book/:id`, `delete-book/:id` | админ |
| POST | `/api/payments/create-payment` | пользователь |
| GET/PUT | `/api/payments/get-payments`, `update-payment/:id` | админ |
| GET | `/api/admin/stats`, `/api/admin/users` | админ |

Категории, авторы и контакты для оплаты: `/api/categories/*`, `/api/authors/*`, `/api/references/contact/1`.

## Приложение Flutter

Читалка встроена в приложение (`assets/reader`) и открывает скачанные книги офлайн через WebView. После изменений в `public/reader` выполните `npm run sync-reader`.

Адрес сервера задаётся при сборке:

```bash
flutter run --dart-define=API_URL=http://10.0.2.2:3000            # эмулятор + локальный сервер
flutter build apk --release --dart-define=API_URL=https://etimolog.uz
```
